# Cedar Grove Academy

## Run locally

```sh
npm install
npm run dev
```

Open `http://localhost:5173`.

## Enquiry and application handoff

The forms validate details in the browser and create a random reference code on your device. Visitors can download a text summary, open a prefilled WhatsApp message to the school, or start another form. Nothing is delivered to or stored by the school until the visitor sends the WhatsApp message.

## Build and start for production

```sh
npm run build
npm start
```
